# MIU Learning Filter Policy

MIU must learn selectively.

## Keep

- Repeated preferences.
- Explicit corrections from Dr. Yehoshua.
- Company doctrine.
- Client-specific presentation rules.
- Confirmed financial standards.
- Product architecture decisions.
- Names, relationships and context threads when useful.

## Do Not Keep As Knowledge

- Raw rambling without synthesis.
- Failed tool attempts unless they reveal a durable bug.
- Secrets.
- Old facts contradicted by a newer correction.
- Generic internet facts unless interpreted into MIU.

## Freshness

Fresh user correction beats older memory.

For finance:

ledger > tool result > same-day doctor correction > old memory > old transcript

For client preferences:

explicit preference > repeated behavior > inferred preference

## Storage

Use:

```text
BIFROST/MEMORY/MIU/knowledge
BIFROST/MEMORY/MIU/profiles
BIFROST/MEMORY/MIU/distilled
```

Use `learning_inbox` only for pending review.
